# Datos

`ubigeo.json`: departamentos, provincias y distritos del Perú, por su código de ubigeo del INEI, para
los combos del pago. Formato compacto: `[código, nombre, hijos]` en cada nivel, en orden alfabético.

- **Códigos y estructura:** [ubigeo-peru-aumentado](https://github.com/jmcastagnetto/ubigeo-peru-aumentado),
  de Jesus M. Castagnetto, con licencia MIT.
- **Nombres con tildes:** tomados de [Ubigeo-Peru](https://github.com/ernestorivero/Ubigeo-Peru) cuando
  coinciden, y completados con una tabla de palabras frecuentes. Algunos nombres pueden seguir sin
  tilde. Conviene contrastarlos con la lista oficial del INEI antes de abrir al público.
